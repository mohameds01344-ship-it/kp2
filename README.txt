KAREN ASHRAF ATTALAH — PORTFOLIO WEBSITE

HOW TO RUN
1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Open index.html in your browser (Live Server extension is recommended).

FILES
- index.html: all portfolio content and sections
- style.css: layout, colors, responsive styling and animations
- script.js: mobile navigation, scroll effects, counters and image gallery
- assets/: portrait, client logos, campaign visuals and portfolio samples

EDITING
- Update text directly in index.html.
- Replace images in assets while keeping the same filenames, or update the image paths in index.html.
- Contact email and phone are in the Contact section near the end of index.html.

The website is static and can be hosted on GitHub Pages or any static hosting provider.
